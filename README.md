# 🍕 FoodieExpress - Food Delivery Website

A complete, responsive food delivery website built with pure HTML, CSS, and JavaScript.

## Features
- 🛒 Order System with cart
- 💳 UPI QR Payment
- 📅 Table Booking
- 🍳 Recipes with step-by-step instructions
- 🤖 AI Food Suggestions based on time
- 📱 Fully Responsive
- 🖼️ 100+ Food Items
